# FAQ Schema

A plain-language reference on FAQ structured data: marking up question-and-answer content so search engines and AI systems understand it as questions and answers, when it helps, how to write FAQs that get used, and the rules that keep the markup valid and honest. Written for operators who want their Q&A content understood and cited.

## The core idea

FAQ schema is structured data, written in JSON-LD, that labels a page's question-and-answer pairs so machines recognize them as exactly that: questions and their answers. Marking up genuine FAQ content this way helps search engines and AI systems understand it, match it to people's questions, and use it. The markup does not invent value; it makes the value of real Q&A content legible to machines that reward clear, direct answers.

## What is inside

- `01-what-it-is.md` structured data and the FAQPage type, plainly.
- `02-when-to-use-it.md` where FAQ schema fits and where it does not.
- `03-writing-faqs-that-get-used.md` real questions, direct answers.
- `04-the-markup-rules.md` keeping it valid and honest.
- `05-common-mistakes.md` the errors that waste or misuse it.

## How this fits

FAQ schema is the structured-data expression of the answer-first, direct-answer approach in the citability and GEO references. The same writing that makes content citable, real questions answered directly, is what makes FAQ schema worth adding. It pairs with those references.
